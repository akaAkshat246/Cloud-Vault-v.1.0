07 — Security

Zero compromise.
Total control.

Security isn't a feature — it's the default. Every file, every time, everywhere.

🔐
End-to-End Encryption
AES-256-GCM encryption applied client-side before any data leaves the device. Server never sees plaintext — zero-knowledge by design.
🗝️
User-Owned Keys
Encryption keys are derived from the user's passphrase using Argon2id. CloudVault holds no keys — only the user can decrypt.
📋
Immutable Audit Log
Every file access, share, and deletion is timestamped and logged. WORM-compliant audit trail — tamper-proof, exportable.
👁️
Transparency Report
Any shared link displays a "Privacy Report" — recipient sees encryption status, what data is exposed, and cannot bypass it.
📱
Biometric Vault Lock
Android fingerprint / face unlock via Capacitor Identity Vault plugin. Auto-locks after configurable inactivity timeout.
🛡️
AI Privacy Guarantee
Claude AI only processes file metadata for search and tagging — never raw encrypted content. On-device processing where possible.
