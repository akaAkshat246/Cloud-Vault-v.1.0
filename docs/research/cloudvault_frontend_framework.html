Security Layer — Zero-Knowledge UI Architecture

🔑
Key Derivation UI
On login, derive master key from password using PBKDF2 (100,000 iterations, SHA-256). Show a progress indicator ("Unlocking your vault..."). Key never touches the server. Store in Zustand useCryptoStore with sessionStorage backup cleared on tab close.
🔐
Web Worker Encryption
Move all libsodium.js operations to a dedicated Web Worker (crypto.worker.ts) so the main thread is never blocked. File chunks are transferred via SharedArrayBuffer (zero-copy). The UI shows a live "Encrypting... 3 of 12 chunks" progress indicator during upload.
🛡
Two-Factor Authentication UI
TOTP (Google Authenticator/Authy compatible). Setup wizard: QR code → verify code → download backup codes. Recovery codes shown once with "I've saved these" confirmation gate. Enforcement: nudge at login, force-gate after 30 days if 2FA not enabled on Pro plan.
📱
Passkey / WebAuthn Support (P3)
Register fingerprint/FaceID as a passkey via WebAuthn API. Show "Login without password" option on supported devices. Fallback to email OTP on devices without biometrics. Platform authenticator preferred over roaming authenticator.
🌐
Session & Device Manager
List all active sessions at /settings/devices: browser, OS, IP, last active, location (approximate). One-click "Revoke this session" button. "Revoke all other sessions" emergency wipe. Show current session highlighted. Refresh token rotation on each API call.
🔗
Content Security Policy Headers
Strict CSP via Vercel headers: default-src 'self', no eval(), no inline scripts, no cross-origin iframes. frame-ancestors 'none' to prevent clickjacking. HSTS with max-age=63072000. Subresource Integrity (SRI) on all CDN assets.
📋
Privacy-by-Default UI Patterns
No telemetry without explicit opt-in. No third-party JS on authenticated pages (Google Analytics only on marketing pages). No cookie consent banner needed for the app (no tracking cookies). Privacy policy UI: one-page plain-language summary before the legal text.

Performance Strategy — Target: Core Web Vitals Green

⚡
Code Splitting & Lazy Loading
Every route is lazy-loaded via React.lazy(). Heavy chunks (PDF viewer, video.js, libsodium, recharts) are split into separate bundles. Initial bundle target: <150KB gzipped. PDF/video modules only load when a preview is triggered.
🖼
Thumbnail Pipeline
Generate 200×200 AVIF thumbnails on upload (server-side Sharp). Store encrypted alongside original. Pre-fetch next 20 thumbnails when user scrolls file grid. Lazy-load all thumbnails via IntersectionObserver. Placeholder: blurred hash (blurhash library).
🗜
Upload Compression
browser-image-compression runs before encryption: resize images >4MB to 80% quality JPEG, strip EXIF metadata. Compress to target 500KB for photos. Show compression ratio in upload UI. Video files: warn if >100MB, suggest desktop app instead.
📡
Request Deduplication & Caching
TanStack Query deduplicates concurrent identical requests. staleTime: 30s for file listings, 5min for user profile, 24h for plan data. Cloudflare edge caches public assets (CSS, JS, fonts) for 365 days with content-hash URLs. Service Worker caches offline shell.
♻
Virtualized File List
react-virtual for folders with >100 files. Render only visible rows + 10 overscan items. Prevents DOM bloat that kills browser performance at 1000+ files. Grid view: CSS grid with fixed 160px columns; list view: @tanstack/react-virtual rows.
🎯
Core Web Vitals Targets
LCP: <1.5s (Cloudflare CDN + AVIF thumbnails) · CLS: 0 (fixed skeleton layouts) · INP: <200ms (Web Worker offloads crypto) · TTFB: <200ms (Vercel Edge Functions) · FID: <50ms. Track weekly in PostHog + Google Search Console.
📱
Mobile-First Responsive Strategy
Base styles: mobile (375px). md: breakpoint (768px) adds sidebar. lg: (1024px) adds preview panel. Touch targets: minimum 44px. No hover-only interactions. Bottom navigation bar on mobile (Drive, Upload, Shared, Settings). Swipe-left on FileCard → quick-delete action.
