LOW
Delta / Block-Level Sync
Only sync the changed blocks within a file — dramatically reduces bandwidth for large file edits.

How to Build It

Use rsync algorithm (or Dropbox's own librsync) to split files into blocks (e.g., 4MB chunks), hash each block, and only upload blocks that changed. For text files, use line-level diff.

Why It Matters

If a user edits 100 bytes in a 500MB video file, CloudVault currently re-uploads all 500MB. Delta sync would upload only those changed 100 bytes + small overhead.
Has it: Dropbox ✓ (only competitor with true block-delta)
Tech: rsync algorithm + content-defined chunking (CDC) + rolling hash

AI Vault Assistant (Claude)
AI-EXCLUSIVE · All Platforms
▾

What It Does

A conversational natural-language interface to your entire vault. Instead of navigating folders, you just ask: "Find the invoice I uploaded last month" or "Summarize the contract named ABC Corp."

How It Works (Under the Hood)

  • User types a query into the chat interface
  • Query is sent to Claude API (claude-sonnet-4-20250514) with a system prompt that includes the user's file metadata (filenames, tags, dates, folder structure)
  • Claude interprets intent and returns structured actions: SEARCH, OPEN, SUMMARIZE, MOVE, SHARE, etc.
  • CloudVault frontend executes the action and displays result
  • Multi-turn conversation: "Now share it with Priya" remembers context from previous message

Example Queries

  • "Find all PDFs larger than 50MB I haven't opened in 6 months"
  • "Who has access to the Q4 report?"
  • "Create a folder called Projects 2026 and move all files tagged #project into it"
  • "What changed between version 3 and version 4 of the contract?"
Tech: Claude API + file metadata indexing + tool-use for actions + conversation history context

AI Document Summarization
AI-EXCLUSIVE · All Platforms
▾

What It Does

Instant Claude-powered TL;DR on any PDF, Word document, or presentation — streamed live inside the file preview without downloading.

How It Works

Summary Types

AI Semantic Search (Vector)
AI-EXCLUSIVE · All Platforms
▾

What It Does

Search by meaning, not just filename. "Show me that thing about the Dubai trip" finds your travel itinerary even if it's named "doc_2025_11_final_v3.pdf".

How It Works

  • On upload, file text is extracted and sent to an embedding model (text-embedding-3-small)
  • The embedding (a vector of 1536 numbers) is stored in a vector database (pgvector or Pinecone)
  • On search: user's query is also embedded → nearest-neighbour search finds semantically similar docs
  • Results ranked by semantic similarity score + recency + user activity
  • Works even if the user uses different words than what's in the document
Tech: OpenAI text-embedding-3-small + pgvector (PostgreSQL extension) + cosine similarity search

🔒 Security & Privacy
🔐
End-to-End Encryption (E2EE)
SECURITY · All Platforms
▾

What It Does

Every file is encrypted on your device before it leaves. Even CloudVault's servers cannot read your files. Only you (and people you explicitly share with) can decrypt them.

How It Works

  • Each file is encrypted client-side using AES-256-GCM before upload
  • A unique file encryption key (FEK) is generated per file
  • FEK is encrypted with the user's master key (derived from password via Argon2)
  • Only the encrypted FEK is stored on server — server cannot reconstruct it without the password
  • On download: FEK is decrypted client-side, then used to decrypt the file
Tech: AES-256-GCM + Argon2id key derivation + Web Crypto API + client-side encryption before upload
🗝️
Zero-Knowledge Encryption (ZKE)
SECURITY · All Platforms
▾

What It Does

CloudVault has zero knowledge of your files. Even if the server is hacked or CloudVault receives a legal demand, they cannot hand over readable file data — because they never had it.

How It Differs from Standard E2EE

E2EE just means data is encrypted in transit. ZKE means the server never holds the decryption key at any point. The key is derived entirely from your password, never sent to the server, and never stored anywhere outside your device.
⚠️ Consequence: If you forget your password, your files CANNOT be recovered. CloudVault cannot reset your encryption key.
Tech: PBKDF2 / Argon2id key derivation on-device + keys never leave the client

Password-Protected Share Links
SHARING · All Platforms
▾

What It Does

Generate a share link that requires a password to access. Send the link publicly, but only people with the password can download the file.

How It Works

  • Share link has a unique token (UUID) stored in DB with: password_hash, expiry_date, download_limit, file_id
  • When someone opens the link, they see a password prompt page
  • On correct password: file is temporarily decrypted and served (or a signed download URL generated)
  • Password is hashed (bcrypt) — CloudVault never stores plaintext password
  • Failed attempts are rate-limited (max 5 tries before lock)
Tech: UUID share tokens + bcrypt password hashing + rate limiting + signed CDN URLs

Cost-Per-File Display (AI-Exclusive)
PLATFORM · AI · All Platforms
▾

What It Does

Shows users exactly how much money each file is costing them in storage fees — in their local currency. Helps users make intelligent storage decisions.

How It Works

  • Storage cost per GB is defined per plan (e.g., ₹2/GB/month for Pro)
  • Each file's size / total storage × plan cost = file's monthly cost
  • Shown as "₹0.04/month" on the file card (on hover or always-on in compact mode)
  • Category breakdown: "Photos cost ₹45/month · Videos cost ₹120/month"
  • Helps users identify and delete expensive files they don't need
Tech: File size metadata + plan pricing config + cost calculation on render

Progressive Web App (PWA)
PLATFORM · Web
▾

What It Does

CloudVault web app can be installed on any device (iOS, Android, Windows, Mac) from the browser — like a native app, with offline access and push notifications.

How It Works

  • Service Worker caches app shell and recently accessed files
  • Web App Manifest defines name, icons, theme color, display mode (standalone)
  • Browser shows "Install CloudVault" prompt after repeated visits
  • Installed app opens without browser chrome (full-screen, like native)
  • Push notifications via Web Push API (for file shares, comments, sync complete)
Tech: Service Worker + Cache API + Web App Manifest + Web Push (VAPID)

AI Smart Folder Rules (P3)
AI · PLANNED · All Platforms
▾

What It Does

Define rules in plain English: "Move all invoices to /Finance/2026 automatically" — Claude evaluates every new file upload and applies matching rules.

How It Works

  • User writes a rule in natural language in the Rules editor
  • On every file upload, file metadata + extracted text is sent to Claude with all active rules
  • Claude returns: matched_rule_id + confidence + action (move, tag, notify)
  • Actions are executed automatically if confidence > 0.85
  • Rules history log shows every action taken automatically
Tech: Claude API rule evaluation + confidence thresholds + rules DB table + audit log

AI Duplicate Detection (P3)
AI · PLANNED · All Platforms
▾

What It Does

Finds near-duplicate files — not just exact hash matches, but "v1 and v2 of the same report" or "same photo with different crop". Shows projected storage savings before deletion.

How It Works

  • Exact duplicates: SHA-256 hash comparison (fast, always-on)
  • Near-duplicates (text files): cosine similarity of embeddings (>0.95 similarity)
  • Near-duplicates (images): perceptual hash (pHash) comparison
  • Weekly scan groups suspected duplicates and presents them as "Review Groups"
  • User picks which version to keep — others archived or deleted
  • Shows: "Freeing 2.3 GB by removing 47 duplicates (saves ₹38/month)"
Tech: SHA-256 + pgvector cosine similarity + pHash (images) + weekly cron scan

What It Does

When a file is shared with someone, both parties can use Claude together in a sidebar — highlight sections, ask questions about the document, and co-annotate. A collaborative AI layer on top of encrypted files.

How It Works

  • Annotations persist and are exportable as a summary report
  • Example: Two lawyers reviewing a contract together — both can ask Claude "What does clause 4.2 mean?" and see the answer together
Tech: Shared Claude conversation context + real-time WebSocket for annotation sync + sidebar UI

GDPR Compliance Center (P2)
COMPLIANCE · PLANNED · All Platforms
▾

What It Does

A dedicated GDPR settings page that gives EU users full control over their data: export everything, delete account + data, view what data is stored, and download the Data Processing Agreement (DPA).

GDPR Rights CloudVault Must Implement

  • Article 15 (Right to Access): "Show me all data CloudVault holds about me"
  • Article 17 (Right to Erasure): Delete account + all files + all backups within 30 days
  • Article 20 (Data Portability): Export all files + metadata as a ZIP
  • Article 7 (Consent): Granular consent toggles (analytics, marketing)
  • DPA (Data Processing Agreement) downloadable for enterprise customers
Tech: Data export job (ZIP generation) + deletion queue with 30-day window + consent DB table
